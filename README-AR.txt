كرنفل AI 4.0 — تذكيرات تقويم الآيفون (مجاني)

ملفات التحديث: index.html, style.css, app.js, agent.js, calendar.js, db.js, sw.js, manifest.webmanifest ومجلد icons.

1. احفظ نسخة JSON احتياطية من الإعدادات أولاً.
2. ارفع الملفات الثمانية إلى جذر مستودع GitHub Pages، مع الحفاظ على مجلد icons في مكانه.
3. بعد النشر افتح كرنفل، ثم الإعدادات > تنزيل ملف تذكيرات التقويم (.ics).
4. افتح ملف ICS على الآيفون وأضف أحداثه إلى تقويم Apple إن أتاح iOS خيار الاستيراد. إذا لم يظهر الخيار، جرّب إرسال الملف إلى بريدك وفتح المرفق في تطبيق Mail؛ تختلف طرق الاستيراد بين إصدارات iOS. تحقق بنفسك من وجود الحدث والتنبيهين في تطبيق التقويم.
5. افتح إعدادات iPhone > الإشعارات > التقويم، واسمح بالتنبيهات.
6. جرّب موعداً تجريبياً قبل الاعتماد على النظام للفواتير المهمة.

التنبيهات: قبل 3 أيام (TRIGGER:-P3D) وعند الموعد (TRIGGER:PT0S). السجلات التي لها تاريخ فقط تستخدم الساعة 9 صباحاً بالتوقيت المحلي للهاتف وقت التصدير.

قيود: الملف ICS لا يُسجل إشعارات تلقائياً؛ يحتاج إلى استيراد يدوي وقبول التنبيهات. بعض تطبيقات التقويم قد تتجاهل بعض VALARM. التعديل/الحذف داخل كرنفل لا يزامن التقويم، وقد يكرر الاستيراد الأحداث. لا توجد Web Push ولا خادم ولا مزامنة سحابية.

الخصوصية: لا ترفع ملفات ICS أو النسخ الاحتياطية إلى مستودع GitHub العام؛ فهي تحتوي على أسماء المواعيد.
